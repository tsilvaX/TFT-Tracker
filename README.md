# TFT Tracker

TFT Tracker is a personal statistics dashboard for Teamfight Tactics, built with Python and Riot Games' API.

## Features (in development)
- Average placement tracker
- Top 4 rate calculator
- Most played units
- Placement trend graph
- Augment performance analysis
- Global playerbase comparison (coming soon)

## Tech Stack
- Python 3.11
- Riot Games API
- matplotlib
- (more coming soon)

## Future
TFT Tracker is currently a local Python tool.
In the future I have plans to evolve it into a 
full web application where users can log in with their Riot account and 
access their personalized dashboard from anywhere.
